# 🌍 UKRTOUR: Heritage & Discovery Tours

An educational web project dedicated to exploring the rich ethnic diversity, traditions, and cultural heritage of Ukraine through curated ethnographic tours.

## 📋 Project Overview
This website serves as an informative platform for travelers and researchers interested in Ukrainian ethnicity. It combines historical insights with practical tour offers, allowing users to "travel through time and tradition."

### Key Sections:
- **Historical Heritage:** Exploration of different ethnic regions of Ukraine.
- **Cultural Tours:** Specialized itineraries (e.g., Hutsul traditions, Bessarabian flavors, Podillia crafts).
- **Visual Gallery:** High-quality imagery of traditional costumes, architecture, and landscapes.

## 🛠 Tech Stack
- **HTML5:** Semantic structure of the web pages.
- **CSS3:** Custom styling, including responsive layouts and typography.
- **Images:** Optimized assets for cultural representation.
